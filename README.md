# Abhishek Singh — Portfolio

[Visit the live portfolio](https://abhi14abs.github.io/portfolio.github.io/)

An interactive full stack developer portfolio built with HTML, CSS, JavaScript, and native WebGL.

- Animated 3D torus-knot sculpture with pointer interaction and a particle field.
- Project filtering and accessible project detail dialogs.
- Keyboard-accessible skill tabs and a Ctrl/Cmd+K navigation palette.
- Responsive mobile layouts, motion controls, and system reduced-motion support.
- Direct links to PixPassVisa, CreateSprint, Postryx, GitHub, and contact channels.

No package installation or build step is needed. Serve this directory using any static web server. GitHub Pages deploys the root of `main` with `.nojekyll`.

`index.html` contains content, `style.css` contains presentation, and `script.js` contains interactions and WebGL rendering. Contact uses email links; no form backend or secrets are required. The project artwork is illustrative. The portrait is retained from the original portfolio.
